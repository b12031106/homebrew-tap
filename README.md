# homebrew-tap

Homebrew tap for [b12031106](https://github.com/b12031106) tools.

## Packages

### ctc — [Claude Token Counter](https://github.com/b12031106/claude-token-count-cli)

```bash
brew install b12031106/tap/ctc
brew upgrade ctc
```

### caf — [caf menu bar](https://github.com/b12031106/caf-menu-bar)

A macOS menu bar app that toggles `caffeinate -dims`.

```bash
brew install --cask b12031106/tap/caf
brew upgrade --cask caf
```
